# ruan-project-reader Skill 2.3 正式版

用户于 2026-10-30 明确确认“本次 2.3 视为正式版本”，并授权完成后推送远端。本版本按工程的 MAJOR.MINOR.PATCH 规范登记为 **2.3.0**，对外名称为 **2.3**。

## 目标与规范依据

在当前授权源码上建立可继续维护的 Markdown 与 Mermaid 项目知识库，按实际执行关系组织模块，以源码证据和用户人工转交的双 AI 协作核验当前层。

完整能力继承 [2.2.0 设计基线](2.2.0.md)；本版本的差异以 [2.3 修复补丁](2.3/ruan-project-reader-Skill-2.3-修复补丁.md) 第四节为准。两份原始材料保持不变。存在差异时适用 2.3 补丁要求，其他既有规则继续适用。

## 正式交付与已知限制

按用户本次明确决定，将当前实现作为 2.3 正式版交付并同步远端；正式构建从 `src/ruan-project-reader/` 生成安装目录和发布清单。源码、清单与本设计使用同一工程版本 2.3.0。

这一正式交付决定不改变验收事实：真实 Goal 自动终止、自动重触发及进程中断恢复仍为 UNVERIFIED，不宣称补丁全部验收已通过。Claude Code、DeepSeek Harness、Windows 的实际加载与全流程、真实远端往返、长期项目恢复以及完整 Mermaid 渲染也仍未验证。核心继续采用标准 Skill 目录、相对资源路径与 Python 标准库，具体平台能力以实测为准。

本版不新增数据库、状态引擎、固定下钻深度、双 AI 自动通信或 Figma 实施任务，也不修改被阅读项目的功能代码。
