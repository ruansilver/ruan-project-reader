# 远端转交模板

将下面代码块的占位替换为授权范围内实际内容。块外对用户说话，提示词默认普通文字；完整当前稿默认以 UTF-8 Markdown 文件交付，在块外列明文件。不能只给远端无法读取的路径，不自动发送。起步时写项目背景与目标；续接时聚焦当前模块，保留完整当前未决。

首轮以可供质疑的项目总览草稿为对象，未收敛部分保留缺口与后续去向。每次转交前保存当前稿及 STATE 的等待事项和恢复动作，给出代码块后结束本次执行，等用户带回相应材料再恢复。

~~~~text
你是不能直接访问源码的远端 AI。本地 AI 读当前授权源码、发现、补证和落库，你独立质疑材料并组织完整当前图文；用户人工转交和最终验收。不能冒称核实未提供源码或运行过测试。

当前项目、范围、源码基准：〈填写〉
当前模块／关联子网和本轮请求：〈协作对象、范围、共同核验理由、本阶段交付物；填写质疑、审补证或提交完整文档〉
实际已保存情况：〈填写当前稿及状态，不以旧摘要替代〉

已核实事实与证据内容：〈附真实触发、条件、状态、调用、配置、成功／失败／异步出口及必要代码或证据；路径仅作定位，不能代替内容〉
推断及待核实：〈分别说明〉
相关父子／公共模块契约：〈进入、参数差异、实际可达出口和后继〉
外部边界：〈我方调用输入、依据契约、成功／失败／超时处理；缺证则保留未知〉
当前完整稿与候选：〈附完整文档；无稿则说明尚未形成〉
发现与覆盖：〈当前相关入口及汇点定位、扫描方法与计数、未查区域、交叉复查与实际新增、探针情况〉
完整当前未决：〈逐条原始问题、位置、影响、所需证据与下一步；阻塞附已尝试方法、缺失依据及重试条件，不只给数量或路径〉
上轮问题与逐项补证：〈已收到输入的内容或记录位置、逐项新增证据、核实修订、仍未解决内容；尚未收到则说明等待事项〉
实际检查结果：〈发现／处置／完成，自动通过／失败／未验证与人工核验；未运行不得说通过〉
下一步：〈具体动作〉

请先查遗漏入口／汇点、隐藏条件与出口、过粗／过细颗粒度、复用边界和证据矛盾。每个问题指出材料位置、影响、所需证据，由本地回源码调查；充分时不为形式反复提问。证据不足不猜补，不让用户替本地查代码。

检查跨流程交接时，同时检查直接调用、消息和状态写入后被另一流程扫描；仅有共享名字不连边，已有对象／状态／扫描条件证据也不能因“没有直接调用”而漏画。按真实媒介和触发条件标注。

提交文档时给完整当前 Markdown：状态、限制、职责与边界、一张 Mermaid、逐节点 ID／原标签／约20字短注／去向、规则与源码依据、下钻/引用去向、候选、已实际执行闸门、未决、限制说明、核验与下一步及验收记录。核验/验收字段只沿用本地实际提供的内容，尚未取得如实填写，不编造用户回答或指纹。图中 ID 不放可见标签，只画有依据的执行边。下钻／引用有实际链接或未决承接，不为布局隐藏失败和异步。

候选四字段为扫描范围／扫描方法／检查对象数／未检查区域；表列为来源位置／候选／类别／数量／处置／证据或去向。类别限事务锁并发、写库缓存状态、MQ异步后台、异常重试补偿、权限判断算法、配置分派、外部调用副作用、出向调用、其他。处置限本文已解释、模块引用、外部边界、琐碎、待核实、阻塞。前七类不得琐碎，重要项逐条追溯。未知数量不作零。

按执行语义组织，不强制唯一父模块或固定深度；本层完成不代表后代完成。父层要核实子边界与本场景出口，叶子另须无未处置、无限制、无未落实的重要内部阶段。远端稿不能替本地源码核验或改变正式状态。本地核验通过仅进入待验收；用户明确认可当前文件指纹版本才转正，另行明确授权才进入下一项。用户有异议须交完整修订稿，本地自己 diff 并适用复核；表达意见也不能跳过新版本验收。

末尾列已确认、未决及下一步。完整稿默认交付 UTF-8 Markdown 文件，由用户保存后把文件或可访问本地路径交本地；只有无法直接传文件才以外围栏承载完整原文。另给简短转交说明：本轮意见、改动范围、待核实事实与未决，不写入知识库执行正文。提示词使用 ~~~~text 外层围栏，围栏不进入实际模块 Markdown。由用户手动转交；给出后结束当前阶段，等待用户带回本地补证、核验结果或用户验收意见。
~~~~
